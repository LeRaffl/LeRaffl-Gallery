# Charts for Ray Wills' article (domestic BEV conversion)

Mirror of Ray's "Global annual vehicle exports by country of origin" chart:
the same six vehicle-exporting countries (China, Japan, Germany, South Korea,
US, Thailand), but showing their **home-market BEV uptake**.

All charts are generated by `scripts/ray_domestic_bev_chart.R` from the
repo's `params.csv` (fitted Weibull trajectories, no refitting), `weights.csv`
and `data/<Country>.csv`. Regenerate locally with

    Rscript scripts/ray_domestic_bev_chart.R

or via the manual GitHub Action **Ray article charts** after new data lands.

| File | Content |
|---|---|
| `domestic_bev_share_2014_now.png` | Fitted BEV share, 2014 → latest data |
| `domestic_bev_share_extrapolated_2031.png` | + dashed extrapolation to 2031 |
| `domestic_bev_share_extrapolated_2035_full_scale.png` | extrapolation to 2035, 0–100% scale |
| `domestic_bev_share_with_weighted_avg.png` | + volume-weighted 6-market average |
| `domestic_bev_absolute_annual.png` | absolute BEV units per calendar year (full years, raw data) |
| `domestic_bev_absolute_ttm_monthly.png` | absolute BEV units, trailing 12 months (raw data) |

Notes: shares are pure BEV (no PHEV/EREV/NEV). Absolute charts use raw CSV
counts, history only.
