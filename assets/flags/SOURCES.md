# Flag and region emblem sources

The country flags in this folder predate this list. Per the maintainer's
recollection (#457) they were taken from **Wikimedia Commons**, where national
flags are generally tagged public domain (official symbols, or too simple for
copyright). The exact Commons file and resolution used were not recorded, so
each country row below links the standard Commons page for that flag and is
marked *believed*: it states the likely origin, not a verified one. If a row
turns out wrong, correct it here. Files named `<country>_<variant>.png` are
byte-identical copies of the country flag (checked by hash); so are
`newzealand.png` and `southkorea.png`, alternate spellings of the slug.
