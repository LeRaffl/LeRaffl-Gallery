# classification/

Powertrain classification for countries whose registry records carry **no fuel
field**, so the gallery derives BEV / PHEV / EREV / HEV / MHEV / ICE from the
model designation. First (and so far only) user: **Argentina** (DNRPA).
Full method, decision log and runbook: [docs/architecture/39-source-argentina.md](../docs/architecture/39-source-argentina.md) §4–§7.

| file | edited by | what it is |
|---|---|---|
| `argentina_rules.csv` | **hand** — the classifier's source of truth | ordered first-match rules: `order, id, class, brand, pattern, kind, reason, evidence, example_brand, example_model` |
| `argentina_models.csv` | generated by `scripts/fetch_argentina.py` | every designation registered in scope → `class`, deciding `rule`, units, first/last seen. Its git diff is the audit trail |
| `argentina_top.json` | generated by `scripts/fetch_argentina.py` | top brands / designations per class, last 12 months (country-neutral schema, doc 39 §5.3) |

Changing a rule: edit `argentina_rules.csv` (keep `order` 1..N; add a real
example), run `python scripts/test_fetch_argentina.py`, commit, then dispatch
**Fetch Argentina data (DNRPA)** with `force = true` so the full history is
re-classified. Never hand-edit the two generated files.

The public source page (`sources/argentina.html`) renders all three.
