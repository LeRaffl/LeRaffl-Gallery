The band is for the fitted line, point by point, and holds only if the transition keeps following an S-shape. How the bands are calculated.

The gallery fits a generalized Weibull curve to the BEV share of each period: share(t) = 1 − exp(v1 · (t − t0)v2), t in calendar years. For Belgium: v1 = −2.411 × 10−6, v2 = 4.639, t0 = 2012, fitted through October 2026, model run 2026-11-09. This is the project's own model, not an official forecast. A policy change or a stall is not in it.

Where the numbers come from

Vehicle registrations in Belgium straight from the FPS Mobility and Transport (DIV, the vehicle registration service) — the monthly open-data files behind ACEA's Belgian figure, published on the 2nd of the following month, about three weeks before ACEA. New cars (Whole), private and VAT-registered keepers, vans, lorries and buses, monthly from 2013, with plug-in and non-plug-in hybrids counted separately.

Raw source

Go and check the numbers yourself:

FPS Mobility and Transport (FOD Mobiliteit en Vervoer / SPF Mobilité et Transports) — monthly vehicle registrations (open data, CC0) ↗

  • FPS Mobility — "Inschrijvingen van voertuigen" (open data page with the monthly Power BI report) — the report's last page ("Downloaden") links the source CSVs; the web page itself sits behind a bot challenge for scripts, the file server below does not
  • DIV monthly registration CSVs (file server) — one file per month, YYYYMM_Immatriculations-Inschrijvingen.csv (from 2025-01, ~220 KB), plus 2013_2024_Immatriculations-Inschrijvingen.csv (28 MB); an aggregate by month, new/used vehicle, new/reused plate, keeper type, engine size, vehicle use group and fuel
  • ACEA — monthly new-car registrations — the cross-check of the Whole series (same register) and the fallback for a month DIV has not published yet

Download

The fetcher asks the file server for the monthly CSVs by name (YYYYMM_Immatriculations-Inschrijvingen.csv), starting three months before the last DIV month in the CSV and stepping forward until the server answers 404 ("not published yet"). There is no directory listing. A run whose target month is already a DIV row in every CSV makes no request; a backfill also reads the 28 MB history file 2013–2024.

Pick the vehicles

Each file is an aggregate — one row per month, new or used vehicle, new or reused plate, keeper type, engine-size band, use group and fuel, with a count. Only new vehicles are counted; the use group decides the variant and, for passenger cars, the keeper type decides Private or Industry.

Checks before writing

The header must be exactly DIV's 14 columns and every row of a monthly file must belong to that month. Unknown use-group, fuel, keeper or vehicle-flag values may not exceed 2% of a month (below that they go to OTHERS with a warning). A Whole month below a quarter of the usual volume is not written. Whole is compared with the ACEA row it replaces and the difference reported (more than 2% is flagged); it is not enforced, because three of ACEA's Belgian rows were wrong.

Each new or changed month re-renders the country. Shares are read from the CSV as column ÷ TOTAL and grouped into three curves. Definitions & scope

AcquisitionFile — downloaded as a data file (XLSX / Parquet / ODS / zip)
Vehicle scopeRegistrations of new vehicles in the month as DIV booked them — a new car counts whether it got a new plate or a plate transferred from the keeper's previous car (Belgian plates follow the owner). Used-vehicle registrations are not written (see caveats).
HEV (full hybrids)DIV's fuel field has "Plug-in Hybrid Petrol / Gasoil / LPG" for plug-in hybrids (→ PHEV) and "Hybrid Petrol / Gasoil / LPG" for every other hybrid (→ HEV). DIV does not tell full from mild hybrids, so HEV here counts both — about 2.5 times ACEA's full-hybrid figure for Belgium, with PETROL and DIESEL correspondingly lower (they hold no hybrid at all). BEV + PHEV + the rest is unaffected.
BackfillEvery variant is DIV from 2013-01 (the start of the history file). The former ACEA rows — Whole quarterly 2018-01…2022-09 and every ACEA row of Vans/HDV/Buses (yearly 2021–2022, then quarterly) — are kept in data/Belgium_legacy.csv. Whole's ACEA monthly rows 2022-10…2026-08 were replaced; each DIV row's note keeps ACEA's figure where it differed.

Caveats

  • Whole runs 86–251 cars (median 155, ~0.4%) above ACEA's monthly figure in every month 2022-10 … 2026-08 but one; BEV agrees within 0–34 cars. PHEV is 1–13% below ACEA in 2025–2026 (ACEA's July 2026 row is derived from a year-to-date difference and is 24% higher). Two of ACEA's Belgian rows were plainly wrong (2023-02: 2,291, 2023-09: 2,965 against DIV 40,056 / 39,034) and are corrected.
  • April 2025 is the exception the other way: DIV's 2025-04 file is about 13% short (32,737 cars against ACEA's 37,812, which equals ACEA's own year-to-date difference; FY2025 ACEA 414,770, DIV 411,384; the Vans / HDV / Buses quarter holding April 2025 is 3–5% low as well). The DIV rows are kept, because their HEV definition matches the rest of the series and the shares are usable, and their notes say CHECK. Volumes for that month are too low.
  • HEV includes mild hybrids (see the hybrid note), so the HEV column is not comparable with ACEA-fed countries; the PHEV and BEV curves are.
  • Private is "not VAT-registered", not strictly natural persons: DIV's keeper type lumps natural persons with legal persons that have no VAT number (associations, some public bodies). Leased cars count by their keeper (the leasing company is VAT-registered, so leased cars are Industry).
  • No Used variant: DIV's "Used vehicle" counts every registration of a used car — imports and domestic changes of keeper alike — and the files cannot separate them, so it does not match this repo's Used definition (first national registration). An open decision for the reviewer.
  • No brand or model: the monthly files carry no make, so there is no market_top table for Belgium. The yearly DIV files (by make and model) are booked at year end.
  • DIV's files are written once and not restated (Last-Modified on the 2nd of the following month). The 2026-09 file was still missing on 2026-10-15 — DIV's publication can slip.
  • Printed under the charts: HEV includes mild hybrids (about 2.5x ACEA's full-hybrid figure), so petrol/diesel run lower than ACEA's. The April 2025 file is about 13% short.

Freshness. Latest period in our store: 2026-10. Update cadence: daily at 17:10 UTC on the 2nd–20th; DIV writes a month's file on the 2nd of the following month (~16:00 UTC).
